# 🧩 Estrutura das Páginas

## 📌 Organização

As páginas foram estruturadas utilizando seções e elementos do Elementor, buscando organizar o conteúdo de forma clara e facilitar a navegação.

## Elementos utilizados

* Cabeçalho
* Menu de navegação
* Seções
* Colunas
* Textos
* Imagens
* Botões
* Rodapé
